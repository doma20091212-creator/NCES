# NCES - New Cairo Escape School

The whole game is about my life in my school which is New Cairo STEM school

everything is on one map. school building on top, football field and the dorm outside

## controls
-move= the normal moving controls- the arrows and the WASD
- shift= this is something like dash but you have a stamina Bar so you get tired tho
- E = it works as an action button (canteen, balls, ping pong, beds, take ur buddy)
- 1 / 2 / 3 in class = noise / catch & throw / volleyball (ONLY when the teacher is writing on the board)
- Q = send ur buddy back to class
- enter = next

## rules
- Mrs. Fatma walks everywhere. if she sees u outside class in a session or with a stolen ball she runs after u. run away or go back to class
- Mr. Hany PE sees whatever he's facing (the red thing). the PE room is not allowed at all
- the principal and Mrs. Samah catch u if u pass by their office while ur skipping
- 3m Amr stays in the dorm and catches u if u go in
- the G10 classes are a desert, u lose health there. if it hits 0 u faint and wake up at the doctor (and if you wonder why G10 floor that looks like a desert, That is because they are boring)
- u get caught = deputy office, Mr. Akef kicks u out. 3 times = expelled
